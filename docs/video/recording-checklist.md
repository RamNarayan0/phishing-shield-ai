# Recording Checklist

## 1. Environment Setup
- [ ] Ensure Laptop is connected to power.
- [ ] Close all unnecessary background applications (Discord, Spotify, etc.) to prevent notification popups.
- [ ] Clean up desktop (hide personal files/icons).
- [ ] Set display resolution to 1920x1080 (1080p) for clear recording.
- [ ] Ensure browser is in Full Screen (F11) or window is maximized.

## 2. Application Setup
- [ ] Run `check-env.bat` to confirm all dependencies are active.
- [ ] Run `start-lan.bat`.
- [ ] Open the React frontend in the browser at the provided LAN IP.
- [ ] Open the PowerPoint presentation (`docs/presentation/Phishing_Shield_AI.pptx`).

## 3. Recording Software Setup
- [ ] Open OBS Studio, Loom, or Windows Game Bar (Win + G).
- [ ] Check microphone levels (ensure it's not clipping into the red zone).
- [ ] Select the correct audio input device (use a headset if possible to avoid echo).
- [ ] Do a 10-second test recording and play it back to check audio/video sync and volume.

## 4. Rehearsal
- [ ] Read through `narration.md` out loud once.
- [ ] Click through the React dashboard presets (Safe, Bank, Fake Job) to ensure the API is responding quickly.

## 5. Final Record
- [ ] Hit Record.
- [ ] Take a deep breath, wait 2 seconds, and start speaking.
- [ ] (Tip: If you make a mistake, pause for 3 seconds, then restart the sentence. You can edit the silence out later).
